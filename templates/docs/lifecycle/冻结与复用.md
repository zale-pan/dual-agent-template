# 冻结输入，避免把历史包再次装进新包

**冻结单位是一项原始输入的确定版本。** 同一文件被实施、裁判和现场复核三处使用，只登记一次，再列三个消费者。跑预检所用源码与实际交付源码必须能逐项核对路径语义和字节。获批清单外的修改不能靠“总数相同”通过。

| 情况 | Steward 的具体操作 |
|---|---|
| 双方均能访问同一 Git 历史 | 记录完整 commit、仓库相对路径和 blob ID。用 `git rev-parse --verify <commit>:<path>` 查身份；从实施方可访问位置按同一 commit/path 读回。存续期间确保提交仍可达。 |
| 未提交、无 Git 或对方无法读取指定版本 | 从已核实的原始文件读取一次；只将该项复制到本轮登记的只读目录，清单写原始位置、快照位置、SHA-256；复制前后及交付读回值一致。未批准前不提交用户的改动。 |
| 新轮要复用上一轮合同 | 对照上一轮清单找到原始合同及指纹。有可达旧版本则直接引用；仅剩旧快照时，先校验历史指纹，再将其作为已确认来源登记一层平坦别名（如 inputs/previous-contract.md），附上原始位置。找不到旧字节则标明缺失，不能用当前文件充当旧版。 |
| 要复用前次通过结果 | 指向轮次短总结和实际覆盖。核对影响判断所依赖的版本、运行条件、命令、夹具。证据已退役且总结不足以支撑的新断言重新运行；不整包复制旧报告。 |
| 真的需要隔离构建或真实克隆 | 只在合同写明该场景时创建一个登记的候选；可用同一候选完成的预检与验收共用。全新克隆本身是验收条件时才另建，并登记释放点。 |

**下发前的停止条件**：源输入清单直接选中了任一期的 package/inputs 或暂存输出，镜像已有 package 树，目标文件重名、大小写冲突、路径越根，或来源/交付指纹不符。回到原始来源或按表中“仅剩旧快照”处理；保留旧包原样。同路径内容确实变化时，登记新版本。

下列 PowerShell 只读检查用于工作单中的**原始项目相对路径**。从选定项目根运行，将示例数组替换为完整输入清单。另对目录和各级祖先检查链接；新项目冻结目录或暂存目录用了自定义名称时也加入禁止来源。历史恢复别名走上表单独核验，不传给本检查冒充原始路径。

```powershell
$inputs = @('README.md')
$seen = [Collections.Generic.HashSet[string]]::new([StringComparer]::OrdinalIgnoreCase)
foreach ($rel in $inputs) {
    $key = $rel.Replace('\','/')
    if ([IO.Path]::IsPathRooted($key) -or $key.Contains(':') -or
        $key -match '(^|/)(\.\.?|\.git)(/|$)' -or
        $key -match '^task_interactions/[^/]+/round-[^/]+/package(/|$)' -or
        $key -match '^dispatch-preflight(/|$)' -or
        $key -match '^/|//|/$' -or !$seen.Add($key)) { throw "非法或重复来源 $rel" }
    $file = Get-Item -LiteralPath $key -Force -ErrorAction Stop
    if ($file.PSIsContainer) { throw "输入须逐文件列出 $rel" }
    $node = $file
    while ($node) {
        if ($node.Attributes -band [IO.FileAttributes]::ReparsePoint) { throw "链接来源 $rel" }
        if ($node -is [IO.FileInfo]) { $node = $node.Directory } else { $node = $node.Parent }
    }
    Get-FileHash -LiteralPath $file.FullName -Algorithm SHA256 -ErrorAction Stop
}
```

若项目把轮次包存放在其他位置，补入实际生成物的精确前缀，并用一条真实源码路径应通过、一条旧快照路径应拒绝验证配置。

模板工具的 build_package 在创建暂存包前拒绝任一任务、任一轮次的包内来源；verify_package 读回时执行同一规则。旧嵌套包用原版本按历史口径复核，保留原裁决。新规则不改写旧包。
